# Tree badges

The fixture for `tree_badges.spec.ts`: a directory of planning documents with
long names, as a real `docs/design/` has, so that a normal-width sidebar has
too little room for every name and every badge at once
(`docs/design/planning-index.md` §7).

Most files carry a `status`, some open questions, or both. `compose.md` has a
declared stage, `csv.md` a stage outside the vocabulary `.vantage.toml`
declares, and `attach-skew-and-contention.md`, `boundary-broker.md` and this
file are not planning documents at all.
